# Bonjour, je suis Nabil SIDHOUM 👋

**Tech Lead .NET** basé à Paris — je conçois et structure des applications métier robustes, évolutives et maintenables.

Plus de 10 ans d'expérience en développement .NET, principalement sur des plateformes utilisées quotidiennement par des équipes internes et des clients finaux. Intervenu d'abord comme consultant sur la conception d'un MVP, puis recruté comme Tech Lead pour reprendre et refondre l'architecture applicative — migration de .NET Framework 4.6 vers .NET 8 en Clean Architecture modulaire, sans interruption de service.

Ce qui me motive : structurer les applications dans la durée, réduire la dette technique et accompagner les équipes pour maintenir une cohérence technique sur le long terme.
